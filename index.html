NeuroWeave

NeuroWeave is an EEG analysis workbench for detecting paroxysmal slow-wave events (PSWEs).

View NeuroWeave on GitHub

About PSWEs

Paroxysmal slow-wave events are transient periods of low-frequency cortical activity observed in animal models and people with epilepsy. NeuroWeave supports local, reproducible EEG import, preprocessing, analysis, visualization, and export workflows.
